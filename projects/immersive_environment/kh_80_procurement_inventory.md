# Neumann KH‑80 Mounting Architecture

## Proposed Mounting Systems for 7.1.4 Configuration

This document describes the anticipated mounting configurations for the **Neumann KH‑80 monitors** used in the system. The goal is to provide a clear description of the mechanical mounting chains so vendors (such as B&H) can verify compatibility and recommend any adjustments.

The system anticipates three primary mounting environments:

1. Floor stand mounting (primary horizontal array)
2. 8020 structural frame mounting
3. Overhead grid suspension (Atmos speakers)

A consistent mounting interface is maintained so speakers can move between systems if necessary.  

The inventory list for thhese configurations can be found [here](https://docs.google.com/spreadsheets/d/1Y4ND_M3c1ZKv1S4Bs0K1mHY8vtbBrymCsntErgicCTM/edit?usp=sharing)  

## TL;DR

| Use | Count | Mechanical Chain | What It Is For |
|---|---:|---|---|
| Floor stand mounting | 7 speakers | Speaker -> LH61 Adjustable L-Bracket -> LH29 Stand Adapter -> Microphone / Lighting Stand | Primary horizontal bed channels: Left, Center, Right, Surround Left, Surround Right, Rear Left, Rear Right |
| 8020 frame mounting | As needed | Speaker -> LH61 Adjustable L-Bracket -> Adapter Plate -> 8020 T-Slot Frame | Mounting speakers directly to the modular structural frame |
| Overhead grid mounting | 4 speakers | Grid Pipe -> Half Coupler -> Mount Plate -> LH46 Telescoping Ceiling Drop -> LH61 Adjustable L-Bracket -> Speaker | ATMOS top channels: Top Front Left, Top Front Right, Top Rear Left, Top Rear Right |
| Universal adapter option | As needed | Speaker -> LH64 VESA / Omnimount Adapter -> Third-Party Mount | Adapting KH-80 speakers to VESA, TV, monitor arm, or other third-party mounting systems |
| Wall mounting option | As needed | Speaker -> LH61 Adjustable L-Bracket -> Wall Plate / Anchor System -> Structural Wall | Fixed wall-mounted installation where permanent placement is needed |

# 1. Floor Stand Mounting (Primary Horizontal Array)

Applies to:

- Left
- Center
- Right
- Surround Left
- Surround Right
- Rear Left
- Rear Right

Speakers will be mounted to **heavy‑duty microphone or lighting stands** to allow rapid repositioning and flexible deployment.

## Mechanical Chain

Speaker  
→ LH61 Adjustable L‑Bracket  
→ LH29 Stand Adapter  
→ Microphone / Lighting Stand

## Components

| Component | Purpose |
|---|---|
| LH61 Adjustable L‑Bracket | Attaches to KH‑80 mounting points and provides tilt adjustment |
| LH29 Stand Adapter | Converts the LH61 interface to a 3/8" microphone stand thread |
| Heavy Duty Microphone Stand | Height‑adjustable stand supporting speaker placement |
| Safety Cable | Secondary tether attached to stand structure |

## Notes

- The **LH61 contains the tilt pivot**, making the **LH32 unnecessary in this configuration**.
- Horizontal direction can be adjusted by rotating the stand.
- Safety cables will be fabricated using aircraft cable and quick links.

---

# 2. 8020 Frame Mounting (Optional / Structural Integration)

The system includes a **modular 8020 T‑slot structural frame** used in the Blended Shadow Puppet environment. Speakers may be mounted directly to this structure when required.

## Mechanical Chain

Speaker  
→ LH61 Adjustable L‑Bracket  
→ Adapter Plate  
→ 8020 T‑Slot Frame

## Components

| Component | Purpose |
|---|---|
| LH61 Adjustable L‑Bracket | Provides tilt adjustment |
| Adapter Plate | Converts speaker mount to T‑slot interface |
| 8020 T‑slot hardware | Allows adjustable mounting along frame members |

## Notes

- This allows speakers to integrate with the **projection and puppet performance structure**.
- Adapter plates may be fabricated or sourced depending on compatibility.

---

# 3. Overhead Grid Mounting (Atmos Channels)

Applies to:

- Top Front Left
- Top Front Right
- Top Rear Left
- Top Rear Right

These speakers will be suspended from an existing **lighting grid composed of 1.5" schedule‑40 pipe**.

## Mechanical Chain

Grid Pipe  
→ Half Coupler  
→ Mount Plate  
→ LH46 Telescoping Ceiling Drop  
→ LH61 Adjustable L‑Bracket  
→ Speaker

## Components

| Component | Purpose |
|---|---|
| Half Coupler | Clamps to 1.5" schedule‑40 grid pipe |
| Mount Plate | Interface between coupler and drop system |
| LH46 Ceiling Drop Adapter | Telescoping drop allowing speaker to hang below grid |
| LH61 Adjustable L‑Bracket | Attaches speaker and provides tilt |
| Safety Cable | Secondary safety line attached to grid |

## Notes

- The **LH46 provides vertical adjustment**, allowing speakers to drop below lighting fixtures or scenic elements.
- Tilt adjustment is handled by the LH61 bracket.

---

# 4. Optional Universal Mounting Adapter

## LH64 VESA / Omnimount Adapter

Purpose:

Allows the KH‑80 to interface with:

- VESA mounting systems
- TV mounts
- articulating monitor arms
- third‑party speaker mounts

This adapter is **not required for the LH61 stand configuration**, but a few units may be useful for future flexibility.

---

# 5. Wall Mounting Option

The **LH61 bracket can also be mounted directly to a wall** when paired with an appropriate plate or anchor system.

Mechanical chain:

Speaker  
→ LH61 Adjustable L‑Bracket  
→ Wall Plate / Anchor System  
→ Structural Wall

This provides a simple fixed installation option if required for permanent setups.

---

# 6. Safety System

All suspended or elevated speakers will include redundant safety systems.

## Safety Cable Construction

Aircraft cable loop  
→ Thimble  
→ Duplex cable clamps  
→ Quick link or carabiner  
→ Structural anchor

## Components

- 1/16" aircraft cable
- wire rope thimbles
- duplex cable clamps
- quick links
- forged eyebolts where required

---

# 7. Design Philosophy

## Modular Interface

All mounting configurations ultimately interface through the **LH61 bracket**, providing a consistent mechanical standard.

## Reconfigurability

Speakers can move between:

- stand mounting
- structural frame mounting
- grid suspension

with minimal hardware changes.

## Safety

All overhead installations will incorporate **redundant safety cables and rated rigging hardware**.
