# Immersive Environment

This folder documents the hardware planning and mechanical mounting approach for the BRPS immersive audio environment, with a focus on the purchased ATMOS-oriented loudspeaker system and related mounting inventory.

## Purpose

Use this folder to:

- Track speaker mounting hardware decisions
- Maintain reference drawings and manufacturer instructions
- Support procurement checks and installation planning
- Keep a consistent mounting standard across floor, frame, and overhead use

## System Scope (Current)

The current documentation centers on a Neumann KH-80 based surround/ATMOS concept with these deployment contexts:

- Floor stand mounting for the horizontal bed channels
- 8020 frame integration for modular structural mounting
- Overhead grid suspension for top channels

The working channel plan in inventory notes is aligned with a 7.1.4 style layout.

## Recommended Workflow

1. Confirm channel assignment and exact speaker count for the installation phase.
2. Validate each mounting chain against the relevant PDF instructions.
3. Finalize procurement quantities for brackets, adapters, stands, and safety hardware.
4. Document any substitutions or field modifications directly in `kh_80_procurement_inventory.md`.
